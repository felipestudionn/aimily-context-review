# Judge scorecard

This is the evidence map for the five official WebMCP Challenge criteria. Every claim about Aimily must be visible in the product, reproducible from the repository or explicitly marked pending.

| Criterion | Winning claim | Direct proof | Final polish gate |
|---|---|---|---|
| Usefulness | Messy fashion context becomes a safe, decision-ready collection revision instead of a loose chat summary | Four signal modalities, exact diff, buyer-ready brief, isolated apply and undo | Keep the video anchored to one buyer voice note and one commercial consequence |
| Originality | The agent participates in product truth through a governed Context Graph, not page scraping or a generic chatbot | Signal to decision to consequence graph, exact-hash policy gate, unselected alternatives, chained receipts | Open the video on the problem, then reveal the graph as the signature visual |
| Execution | The full lifecycle is server-enforced, native, tested and publicly reproducible | Chrome 151 native harness, 232 tests, isolated build, signed state, replay protection, seven-check receipt verification, responsive QA | Cold-run the public URL twice and preserve a final evidence bundle |
| Thoughtful WebMCP use | Tools are narrow, page-scoped and dynamically reveal only valid next actions | Seven intent tools, strict schemas, structured results, `readOnlyHint`, `untrustedContentHint`, session-first registration and a live authority boundary proven identical to native inventory | Show the changing native tool inventory in the final recording |
| Human-agent experience | The human owns the consequential decision while the agent carries context, computes impact and performs approved work | Human-only approval, exact artifact hash, state-aware copy prompts, approved brief, verified receipt chain, immediate undo | Make approval, apply receipt and recovery legible without narration |

## The single memorable sentence

Most agent demos show how much an agent can do. Aimily shows how confidently a team can let an agent participate in decisions that become product truth.

## The 75-second proof order

1. A buyer voice note enters through the personal agent.
2. Native Site Tools show three page-scoped intents.
3. The agent drafts four connected changes.
4. The Context Graph exposes evidence, consequence and inference.
5. The human approves one immutable hash.
6. Apply appears only now.
7. A chained receipt inside signed state appears and production remains unchanged.
8. Undo restores the preview while the record persists.

## Red-team questions the package must answer

| Judge concern | Answer in product |
|---|---|
| Is this a dressed-up chatbot? | No. The agent calls typed domain intents against signed workspace state. |
| Can the agent approve its own work? | No. Approval is absent from the WebMCP tool surface and enforced server-side. |
| Is the graph decorative? | No. It is generated from the same deterministic revision artifact and exercised by evals. |
| Is untrusted content treated as instruction? | No. Source-bearing results are annotated and prompt-like evidence is preserved as inert data. |
| Is apply a production mutation? | No. The Challenge deployment can change only its signed isolated preview. |
| Is undo cosmetic? | No. It is a server transition that restores original values and adds a chained receipt. |
| Can the receipt trail be trusted? | The server recomputes seven integrity invariants before signing the next session state and exposes the result to the page and agent. |
| Does the page rely on DOM or screenshots? | No. Tools call a same-origin server boundary and the shared domain layer. |
| Is native WebMCP actually tested? | Yes. Chrome 151 discovers and executes the complete dynamic lifecycle on public HTTPS. |

## Claims deliberately excluded

- No claim of production collection mutation.
- No claim that every ChatGPT Desktop account already exposes Site Tools.
- No claim that declarative WebMCP is production-ready.
- No claim that WebMCP replaces Aimily's remote MCP or product architecture.
- No claim based only on animation, mock output or a screenshot.
